## Hakkımda

Yaklaşık 5 yıldır backend ağırlıklı yazılım geliştiriyorum. .NET ve Java ekosistemlerinde, özellikle mikroservis ve event-driven mimarilerde çalışıyorum.

Bu süreçte **BMW Türkiye** dijital platformlarında (Mini Prime, BMW Prime, MyBMW), **havalimanı iç mekan konumlandırma** sistemlerinde (IGA, Sabiha Gökçen) ve **araç filosu takip** projelerinde görev aldım. Yüksek hacimde gerçek zamanlı veri işleyen sistemleri kurmayı, çalıştırmayı ve sade tutmayı seviyorum.

- Şu an derinleştiğim konular: **Java / Spring Boot**, **mikroservis mimarisi**, **React / Next.js**, **PostgreSQL**
- **Konya Teknik Üniversitesi**'nde Bilgisayar Mühendisliği yüksek lisansı (dağıtık sistem iletişimi, gerçek zamanlı veri)
- Yapay zekâ tarafında: **ML.NET**, yerel LLM'ler (Ollama), **MCP**
- Backend mimarisi, event-driven sistemler ve ödeme entegrasyonları üzerine konuşmaya her zaman açığım
- En hızlı ulaşım: [LinkedIn](https://www.linkedin.com/in/karani-karaman-b12850191/) · karamankarani42@gmail.com
